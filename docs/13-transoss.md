# TransOSS 比赛适配与逐轮验证

2026-10-07按用户建议，实际训练作者TransOSS比赛适配版，在同一身份隔离验证集上加权分为0.5604962981，超过DINO独立入口版0.3554768790。训练第73轮自动早停，选中第53轮；最佳权重重新加载和算力机、本机独立标量复算均通过。匿名完整证据见[evidence/2026-10-07-transoss.json](evidence/2026-10-07-transoss.json)。

## 提分分解

对同一验证集的两版逐查询排序进行配对检查，匿名结果见[提分分析](evidence/2026-10-07-transoss-gain-analysis.json)。O2S的正确身份进入前10名比例由65.62%升至86.27%，S2O由63.73%升至85.99%。O2S新增263个首位正确查询、损失86个，净增177个；S2O新增233个、损失69个，净增164个。收益包含更多正确候选进入前10名，不能仅用候选内部排序变化解释。

按现有评分权重，O2S贡献+0.10610，S2O贡献+0.10480，O2O抵消0.00587，合计+0.20502。这是本地评估方向分解，不是算法组件的因果贡献，也不是官方方向分数；官方目前只有总分。

领域配对预训练、全骨干微调、身份损失和数据增强共同变化，可能改善跨模态特征。旧DINO已经有独立光学/SAR入口，因此不能把收益简单归因于新引入双入口。旧版只训练最后4个Transformer块且没有增强，新版训练全部骨干并使用随机水平翻转。DINO每轮89步，12轮共1,068次更新；TransOSS每轮177步，最佳53轮共9,381次更新，约8.8倍。即使比较各自第12轮，也不是等更新次数、等优化设置的消融。

TransOSS第12轮为0.44071，继续到最佳第53轮增加0.11978；最佳比第73轮末轮高0.01280。后者只衡量这条轨迹中选最佳检查点避免的退步，不能把全部0.20502提升归功于早停。第0轮仅0.10016，也说明这份领域初始化需要配合身份微调。要区分预训练与训练流程的贡献，需要控制其他设置，分别比较初始化及DINO的充分训练。

官方绝对提升0.07511小于本地0.20502。验证集选最佳轮次及验证/官方任务分布差异都可能影响差距，现有结果不能判断各自占比。仅按方向使用DINO的O2O和TransOSS的跨模态结果，本地分数算术上为0.56637，比纯TransOSS仅高0.00587；这没有生成新提交，也不保证官方收益。跨模态前10名命中约86%，但首位约46%，仍有较大识别和排序空间。

## 实际方法

使用[作者代码](https://github.com/Alioth2000/Hoss-ReID)固定提交bd9b9028；ViT主干原文件未改动，MIT许可与归属保留在track6/vendor。使用[作者模型仓库](https://huggingface.co/Alioth2000/TransOSS)固定fb4403a0版本的vit_b512_pre.pth场景配对初始化，完整348,477,907字节SHA-256为bd8f1dd35cfb6bc6c2a111fa3f8e4a415bfe6e04231aab7cf0f076a97bc2b5f9。模型仓库声明CC-BY-4.0；资源登记见[清单](../resources/transoss-paired-vitb16.json)。未使用HOSS身份训练检查点。

加载通过weights_only=True执行，要求光学/SAR两个patch入口、模态嵌入和全部骨干键严格匹配。作者预训练位置网格16×8显式插值为比赛16×16，输入为完整256×256图。没有有效物理尺寸/GSD元数据，关闭尺度嵌入。身份训练使用作者BN neck、CE和无margin欧氏batch-hard triplet，全骨干SGD；每批16个身份各取1张光学和1张SAR图，独立随机水平翻转。检索使用BN之前的CLS特征和余弦排序。

这属于比赛适配；方形输入、缺失尺度、采样与增强不等同于完整HOSS论文复现。比较中DINO的骨干、损失、优化器和训练预算也不同，不能把全部分差归因于配对初始化或早停。

## 训练与验证

复用固定identity-v1划分和种子20261001，2,819个成对训练身份；验证身份不用于梯度更新。第0轮先评估初始化，此后每轮记录三个方向R@1/mAP@10和0.45/0.45/0.10加权分。最多200轮，至少30轮，耐心20轮，累计最小提升0.001；任何严格最佳都原子保存，相同分数保留较早轮次。学习率0.0005、SGD动量0.9、权重衰减0.0001，5轮预热乘以200轮余弦衰减，最低系数0.1。

运行另外限制训练命令最多1,800秒，以留出模型取回和关机时间。如果时间限制先触发，保留未完成原始运行记录，并在新目录单独恢复最佳检查点评分，不宣称验证耐心已耗尽。正常早停则在原运行内重新加载最佳检查点，要求评分复现；两种情况都用独立标量评分程序及本地文件摘要再次核验。

验证集参与最佳轮次选择，当前比较是方法筛选证据；另一身份划分必须从公开初始化重新训练才构成进一步确认。本地分数不能替代官方Public分数。首次运行只做验证；随后用户批准提交，用最佳第53轮检查点恢复生成267个Query的测试预测，17:30平台接收，今日3/3次。评审完成，官方Public为0.5144077656525573，比原首版0.43929340277777784增加0.0751143629、约17.1%，成为当前最好提交；收益小于本地分差，未据此推断其他队伍方法。官方结果见[第三版记录](evidence/2026-10-07-third-submission.json)。追加推理0.28元，今日合计8.40元，实例已关机。
