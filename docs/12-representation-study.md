# 表示研究：可见证据、缺失和身份

2026-10-02。用户希望给经验积累、结构辨认和寻找合适表示留出时间。算力机已由用户下线；本轮在本地阅读原始样例、核对理论和整理反例。没有新增训练、外部权重或排行榜成绩。

目前形成的研究假设是：**为每幅图保留可见的局部证据、相互关系及尚不能判断的部分，再比较这些证据对同船与异船两种解释的支持程度。**尚未找到能可靠提取这些证据的表示，也未证明它会超过现有独立入口基线。本章用于明确什么值得寻找、什么不能直接假定。

## 1. 先看同一个问题中的不同样例

新观察册只从两组划分共同的训练身份取样，不新增验证集或初赛图像查看。通过原有异常排除后，取每身份恰好1光学/1SAR的6组，以及至少2光学/1SAR的6组，共12个身份、32张图。各组用独立命名空间的哈希排序选取，seed=20261002；多视图组刻意多取，不能据这12组估计总体发生率。

工具保存原始256×256像素、方向、亮度和色彩，逐像素检查无损PNG导出，并与此前全量审查的32个像素摘要重新核对。图板中的同船关系来自官方标签；这些观察不是人工独立身份核验，也不是部件真值标注。

| 匿名案例 | 实际可见内容 | 对表示的约束 |
|---|---|---|
| P01–P03 | 光学包含不同程度的海面、码头或填充；SAR主要呈局部亮区 | 同样的亮度阈值在两个模态中选择的对象不同，不能直接当作统一船体区域 |
| P04 | 两种图像都缺少清晰部件细节 | 主轴可计算，不等于船首/船尾可确认；低信息图应保留歧义 |
| P05 | 光学主体连续，SAR两端亮而中部较暗 | 暗区可以是“未观察到可靠回波”，不能直接解释为实体结构不存在 |
| P05–P06 | 不同标签的光学外观同样细长、背景相近，SAR亮区布局不同 | 粗轮廓或类别一致还不足以确认实例；局部差异是否可靠仍需判断 |
| P07 | 光学重复色块与SAR横向亮带提供可能的轴向次序线索 | 目前不能把某条亮带确认为某个甲板部件；需要允许局部无对应 |
| P08、P10 | 同标签多张SAR的亮区分布不同 | 同身份也不保证稳定的亮区面积、局部强度或完整轮廓 |
| P09、P11、P12 | 多张光学图布局很接近，颜色、清晰度有所差异 | 多个文件未必等于多次独立成像；缺少来源证据时保留“独立观测或处理变体”的不确定性 |

|---|---:|---:|---:|---:|

统计范围是这两组共2,435张光学图，不是全部训练数据或测试数据。图像级计数也不等于2,435次独立观测。多图身份与窄幅、黑底图像的关联在样例和此统计中都很明显，但其采集、裁剪、增强来源尚不清楚。

O2O要求同身份至少有两张光学图，天然选择了不同的身份/图像子群。因此第10章发现的O2O与O2S差异，除模态因素，还包含样本选择及图像呈现因素。**O2O高分无法单独证明跨模态所需的船体结构已经被学到；多光学图身份上的方法成功也不保证迁移到普通单对身份。**这不改变官方三个方向的权重和现有身份隔离划分。

### 一个小的几何反例

P02光学图在阈值8下，包围框是整幅256×256图；同船SAR的包围框为70×129。P05光学图在8、32、64、128四档阈值下的包围框均为256×256。P08第一张SAR的阈值从8改为128时，亮区包围框高度从230变为111像素。

这些数字描述亮像素，不是物理船宽/船长。主轴二阶矩各向异性也只是掩码统计，不是经过校准的定位置信度。依靠该阈值自动确定船体坐标系，目前缺少成立的前提。

## 2. 把可逆变化与信息缺失分开

对于完整离散图像，90度旋转及其逆操作保留像素信息。有限分辨率下的任意角度插值、裁剪、量化以及成像不可见区域则可能丢失信息。SAR还取决于散射及观测几何，不能用光学灰度变换概括。[ASF成像原理](https://hyp3-docs.asf.alaska.edu/hyp3-docs/guides/introduction_to_sar/)讨论了侧视畸变、阴影和散斑；其地形示例不能证明某张船图发生了具体的叠掩。

Soatto与Chiuso把任务充分性与对无关变化的不变性放在一起分析，并对遮挡引入可见区域和局部表示。其结论有明确成像及统计假设；不能概括成“不变性一定损害区分力”，也不能把光学模型直接当作SAR定理。本文从中借用的是检查表示是否保留任务信息的标准。[ICLR 2016论文，第2节、第3.1节](https://arxiv.org/pdf/1411.7676v9)

### 一个可穷尽的反例：保留三分之二信息也不能任意压成同一个编码

以下为自构的数学例子，不是比赛数据的误差上界。设8种对象分别为三个二进制属性的所有组合。每次观测恰好看见两个属性，并明确知道哪一个属性缺失，例如 `01?`。这个观测与完整对象 `010`、`011` 都相容。

假设要求一个确定性表示对**任意一个属性缺失都完全不变**，即完整对象与其每个局部观测编码完全相同。那么：

```text
f(010) = f(01?) = f(011)
```

任意只差一位的两个完整对象都有同样的关系。8个对象构成的三维立方体通过12条这样的边全部连通，因此所有完整对象都被迫得到相同编码。反例不需要使用完全空白的观测；局部观测始终保留两个属性。

本轮穷举核验了8个完整状态、12个局部观测、每观测2个相容状态以及单一连通分量。结论只否定“在这套观测规则下，完全删除不变性还能区分全部对象”的要求。现实中的软对比损失、有限增强及带条件的表示并不等于这项要求；这不是现有DINOv3表示已经坍塌的证明。

还有一个容易混淆的关系：**真实的同一身份具有传递性，观测上的相容性未必具有传递性。**一幅清晰光学图只支持A，一幅稀疏SAR同时支持A/B，另一幅清晰光学图只支持B。两幅光学图分别可以与SAR相容，却不因此属于同一艘船。把中间观测的歧义抹掉，会混淆这两种关系。

## 3. 值得继续积累的三种表示语言

这里比较的是描述问题的方法，没有选定新网络。

### 一个确切但有限的一一对应

先把四个已对齐的局部写成符号序列：`A B A C`。假如另一种成像只把局部类型的外观一一重命名，可能看到`7 2 7 5`。符号本身完全不同，但“第1处与第3处同类，其余各自不同”保持不变。用关系表记录`R[i,j]=两处是否同类`，得到：

```text
        1  2  3  4
    1   1  0  1  0
    2   0  1  0  0
    3   1  0  1  0
    4   0  0  0  1
```

这里确实存在严格对应：**把只差符号一一重命名的序列视为同一类后，每一类恰好对应一个这样的等价关系表。**正向显然保持关系；反向可以按首次出现顺序为关系表的各等价类命名，重建规范序列`0 1 0 2`。因此关系表在这个简化问题中恰好消除了名称，同时保留了重复结构与次序。

`A A B C`与`A B A C`的计数直方图相同，关系表却不同。由此可以精确解释“保留关系”比仅保留部件数量多保留了什么。本轮穷举长度4、字母表大小3的81个序列，得到14种规范序列和14种关系表，逐项一一对应。这是对小例子的核验，不是新的数学定理。

把它用于真实图像需要三个尚未满足的前提：能够定义可靠局部；知道或推断局部位置的对应；跨传感器仍保留足够的内部相似关系。SAR可能使光学上相同的两个局部呈现不同散射，或把不同局部都变成亮斑；任一情况都破坏“一一重命名”的条件。若所有局部彼此不同，关系表还会退化为单位阵，无法区分许多不同对象。P07只是让这个语言值得观察的例子，没有证明这些前提。

因此，对真实任务的启发是保留可置信的关系并标出未知，而不是把这张理想关系表直接当作已经找到的舰船身份指纹。

| 表示语言 | 想保留的关系 | 需要的前提 | 已有反例或边界 |
|---|---|---|---|
| 船体坐标中的轴向次序、相对间隔 | 部件先后关系，以及整体旋转之后仍存在的布局 | 可靠定位主体；船首/船尾不确定时保留两个方向；尺度仅作图内归一化 | P04细节不足，P02阈值选到背景；SAR亮区不能自动命名为部件；相同型号可能共享布局 |
| 图像内部的自相似关系 | 同一幅图中哪些局部互相相似，再比较两图中的关系排列 | 两种成像下某些内部关系可重复，且这些关系能区分实例 | P07只提供候选线索；散斑、背景、重复甲板结构可能改变关系或造成异船巧合 |
| 带未知状态的局部证据及部分对应 | 哪些局部可信、哪些可互相支持、哪些暂时没有对应 | 能评估可见性与错误对应；对异船也检验；禁止用“都未知”无限宽容 | P05/P08支持保留缺失，但目前没有真实可见性标签或标定好的置信度 |

局部自相似的早期工作把跨图外观匹配改写为图内关系的匹配，并保留局部的空间组织。论文还丢弃缺乏区分力的描述子。这提供了一个有用的描述角度，但其类别/模板匹配示例不证明同型号舰船可分，也不证明这些关系在SAR中稳定。[Shechtman与Irani，CVPR 2007，第2–4节及图3](https://www.wisdom.weizmann.ac.il/~vision/VideoAnalysis/Demos/SelfSimilarities/SelfSimilarities_ShechtmanIrani07.pdf)

SuperGlue把匹配写成部分分配，并给无法匹配的局部留出未匹配出口。值得借鉴的是“允许没有对应”这项语义。其局部点通常对应同一三维点，跨光学/SAR能否满足这一条件尚待检查。图内局部的分配约束也不能套到全体Query/Gallery：本题可以有多个正确Gallery图。[SuperGlue，CVPR 2020，第3节及图3–4](https://openaccess.thecvf.com/content_CVPR_2020/papers/Sarlin_SuperGlue_Learning_Feature_Matching_With_Graph_Neural_Networks_CVPR_2020_paper.pdf)

三篇论文只用于阅读，核对了上述章节和相关图页，没有宣称全文复现。没有导入它们的代码、数据或权重；论文较早公开不等于某项具体权重已经完成日期/许可审查。原文摘要、版本、阅读范围见[研究证据](evidence/2026-10-02-representation-study.json)。

### 用“支持何种解释”连接这些语言

令H表示两幅图属于同一身份，一个概念性的比较量是：

```text
L(o,s) = log p(o,s | H=同船) - log p(o,s | H=异船)
```

这是统计建模目标，当前没有这些分布的可靠估计，也不是新增评分器。它提醒我们分别看三件事：两图中有没有共同证据；这种共同证据在异船中是否也很常见；观察条件是否足以把某项差异当作反证。

细长轮廓在许多船上出现时，其证据较弱。只有确实可观察到某部件时，该部件不一致才可能构成较强反证。未观察到部件可降低确定性；不能自动给予所有候选高分。多个高度相关的局部证据也不能当作独立证据重复累加。

O2O还可能使用颜色、外观细节等在光学内部可靠的线索。一个服务三个方向的表示应保留按观测类型取用证据的空间；没有依据要求所有信息都缩成跨模态的最小公共部分。

## 4. 现有检索结果允许我们知道什么

上轮已实现、此前尚未归档到分章文档的CPU候选集诊断现已补齐证据。分析对象是**固定patch入口、末4块已微调12轮的旧DINOv3-B/16**，不是全冻结特征基准，也不是第11章的独立入口新基线。

| 划分 | 方向 | 实际R@1 | 至少一张正例进入前10 | 至少一张正例进入前50 |
|---|---|---:|---:|---:|
| 1 | O2S | 20.78% | 67.97% | 86.67% |
| 1 | S2O | 21.57% | 64.99% | 85.01% |
| 2 | O2S | 20.21% | 63.78% | 87.40% |
| 2 | S2O | 20.03% | 61.61% | 86.51% |

O2O前10/50召回均为100%；其实际R@1分别86.36%/75.00%。三个方向的原始R@1、mAP@10及两种AP分母均重新计算，并确认前十排序与原报告一致，完整表在[诊断证据](evidence/2026-10-02-shortlist-diagnosis.json)。原实际加权分为0.33659/0.31150。

此外，工具使用已知验证标签，把固定候选中的正例理想地排在最前，计算标签oracle：前10候选的加权上界为0.69360/0.66058，前50为0.87220/0.88156。未进候选的正例仍计入AP分母。**这些不是图像模型成绩，不是信息论上限，也不说明图像重排器能达到该分数。**它们仅说明当前排序与已知标签之间还有多少空间。

这给研究留下两个独立问题：正确船未进候选时，缺少了什么信息；已经进入时，有什么可靠证据能把它和相似船分开。第11章独立入口模型的完整特征未保存在本地，算力机已下线，尚未对它做同样诊断。不能把旧模型的候选覆盖直接归给新模型。

## 5. 当前取舍与仍然开放的问题

保留独立入口DINOv3-B/16作为已有实测参照。当前研究优先级是理解表示需要保留什么，以及什么时候应承认局部信息不足；暂不因为一个形式好看就添加网络模块。

最值得继续追索的是**在可见区域内保留布局、允许局部缺失、对常见结构保持克制的比较方式**。若连训练原图上都难以稳定指出跨模态对应的局部，复杂局部匹配还没有足够基础；若只能区分类别而不能区分相似异船，结构表示也未满足任务。

之后任何实现都应带着反例进入验证：保留局部次序是否真的胜过打乱次序；未匹配出口是否仅仅放宽了异船匹配；推断出的轴向坐标是否主要跟随黑边或亮斑；改善是否只发生在多光学窄幅裁剪子群。可见性、置信度、局部对应还都未成为真值。不能用这份观察册挑验证阈值或报告识别收益。
