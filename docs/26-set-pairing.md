# 集合级配对训练

2026-10-09，本地RTX 4060 Ti 16GB，无付费GPU。第五次官方提交已评审Public **0.7185908013668432**，比第四版增加0.0486755952。该反馈支持第五版整体改动，但不能单独分离冻结CLS判别器、局部交互和辅助目标各自贡献。官方截图与摘要见[第五次提交证据](evidence/2026-10-08-fifth-submission.json)。

## 预先固定的对照

上一轮动态难例提高独立检索时，集合配对可能下降。因此本轮直接训练候选之间的双向竞争，比较双向CE和确定性log-Sinkhorn匹配NLL。Sinkhorn交替平衡行/列，是[Learning Latent Permutations with Gumbel-Sinkhorn Networks](https://arxiv.org/abs/1802.08665)讨论的连续匹配近似；本实现没有Gumbel采样，不宣称完整复现论文。

两组均使用训练身份内的O/S CLS均值构造对称余弦难度。每轮随机排列2819个有双模态图的训练身份，以未使用身份为锚点，选其最相似的31个剩余身份，消耗每个身份一次，共89批；每个身份随机选一个O和一个S观测。SAR列随机重排，以真实训练身份构造置换标签，避免把位置当作答案。所有组块与难度计算均不读取验证或测试身份。

每批计算完整32×32矩阵；最后一批仅3身份。双向CE同时监督O→S和S→O，Sinkhorn使用10次行列log归一化后对真实匹配取负平均log值，有限迭代只近似行列双随机约束。两组均在整体logit及独立局部logit上使用对应目标，局部辅助权重0.5。两组候选、SAR置换、初始权重、每轮89次更新和采样摘要逐轮比较；相同种子20261008/20261009，各24轮，每2轮按原development独立检索选择模型，不按集合模拟重新挑轮次。

模型仍是第五版的局部交互架构，骨干和CLS头冻结，AdamW学习率0.0003、weight decay 0.01；原生余弦前50候选、O2O、局部缓存和独立评分协议保持。与第五版原独立11候选CE的比较同时改变了采样/候选数量，因此不能将差异全部归因于损失公式；双向CE与Sinkhorn之间才是匹配候选的目标对照。两半验证身份在先前研究已经使用，报告组不能称为新独立确认集。

训练入口为`tools/train_local_pair_verifier.py --set-objective dual|sinkhorn --set-size 32 --local-aux-weight 0.5`，须通过`tools/run_job.py`持共同GPU锁运行。原训练默认`--set-objective none`；源码快照与SHA随新实验保存，局部模型架构文件不修改。数学测试检查行列归一化、置换等变、有限梯度、错标拒绝与困难组完整覆盖。

## 下一步取舍

本轮没有找到从0.72明显跨越到0.9的训练目标改动。优先级转回更强的跨模态表征：结构能量归一化、SAR去噪/训练模态对齐，先设计相同训练身份、早停和候选池的对照。集合训练保留双向CE作为小幅候选，暂不扩大本轮Sinkhorn配置。所有新候选仍须同时检查独立检索与集合配对，并保留验证复用和真实测试结构差异的限制。
