完整包共有 9,498 个条目，含 6 个目录、9,489 张 TIFF、1 个 CSV、1 个 JSON 和 1 个 README。授权页面的 1,026 项预览不是完整包计数。证据见 [压缩包摘要](evidence/2026-10-01-archive.json) 和 [全量数据审查](evidence/2026-10-01-data-audit.json)。

## 全量图像、重复与异常

9,489 张 TIFF 均完成全量像素解码，都是单帧、256×256×3、uint8；未发现不可解码或尺寸/位深异常。全部 SAR 为三通道灰度复制。Gallery 中另有 13 张标为光学的图像也为三通道复制，不能仅据灰度判定模态。

按文件摘要与像素摘要均发现 256 个完全重复组、涉及 513 张图像。其中 212 组跨 Query/Gallery，27 组仅在 Query，10 组仅在 Gallery，6 组仅在训练，还有 1 个训练/Query/Gallery 共享的全黑组。测试重复保留，提交仍覆盖每个原始 Query。

训练中的 6 个非恒定重复组涉及 12 张图像，标签给出不同身份；另有 1 张训练全黑图像。保守基准从训练/验证中排除这 13 张，不修改原件。全黑图像在 Query、Gallery 也各有 1 张，继续生成合法候选。

近重复审查使用浮点灰度 dHash（汉明距离≤2）并要求归一化 16×16 缩略图相关性≥0.9998，共识别 78 对候选。此阈值是实验防泄漏启发式，不能当作身份真值；只把涉及训练的候选连接成身份组件并整体划分。训练/验证身份、完全重复像素及采用的近重复连接均无跨区重叠。

逐图摘要、身份、异常清单和重复 ID 留在 Git 之外的 `local/data-audit/`。仓库只保留汇总统计；上述结构正确和解码通过不代表所有身份标签均正确。
