# 数据与审查状态

## 官方描述

图像为256×256、uint8、TIFF。SAR的3通道是灰度复制，不能将其解释成真实彩色图像。训练输入包括train/optical、train/sar及labels.csv，字段为image_id、ship_id、modality、image_path；初赛测试包括Query、Gallery和task.json。

每个Query至少有1个有效正确匹配，符合检索模态的候选至少10张。真实数量、身份数量、每身份跨模态配对比例和任务结构仍待文件审查。

## 本轮授权页面观察

[第6题初赛数据集](https://www.heywhale.com/org/cunsl/dataset/6abca72bcd87a9ae0e90b857/file)已可访问。显示赛题6-初赛.zip，398.1 MB，压缩内容预览1026项；所见前500项主要是初赛测试数据/gallery。预览数量不作为完整解压文件统计，也不能凭前500项断言训练数据不存在。

浏览器下载尝试未取得已核验的完成文件，尚无SHA-256或CRC证据，不能视为数据就绪。概述没有额外数据文档。实际包目录可能与示意input路径不同，读取器需通过正式文件确认。当前按用户指示先搭建基础实验仓库，后续接入正式文件。

## 待执行的审查

| 检查 | 输出 |
|---|---|
| 完整性 | 文件大小、摘要、CRC、目录与扩展名计数 |
| 图像 | 全量解码、尺寸、位深、通道数与SAR通道复制 |
| 标签 | 字段、空值、ID重复、路径存在与安全性、身份/模态计数 |
| 查询任务 | 真实task.json结构、Query覆盖、模态映射、至少10个候选 |
| 隔离 | 身份级训练/验证划分、原始图像重复与近重复 |
| 异常 | 极小文件、空图与不可解码样本单独登记，不因文件小直接删除 |

暂时只做测试包结构检查，不利用其隐藏身份或额外信息建立训练标签。原始文件与逐图记录留在local/或数据盘；仓库只保存适合分享的审查总结。
