# 研究执行与验证计划

## 顺序与验收

当前已完成数据审查、身份隔离协议、初始基准、DINOv3通用/卫星对照与两组划分的监督微调。固定协议见[第7章](07-validation.md)，初始基准见[第8章](08-baselines.md)，新结果与复现命令见[第9章](09-modern-models.md)。进一步结构研究仍需同预算消融，不能据两组本地验证宣称最佳方法。

1. 完成官方包下载，运行摘要/CRC审查；确认是否含训练数据，再核对标签和真实task.json。
2. 全量解码TIFF，统计模态、尺寸、通道与身份数据；核验灰度复制和异常文件，保留可追溯记录。
3. 使用身份隔离的固定本地验证协议；三个检索方向分别列出R@1、mAP@10与加权分。验证身份不进入训练。
4. 在具体训练包与来源清单齐全后登记通用检索基准；所有外部权重先完成2026-09-01公开日期与许可审查。
5. 模型研究只在固定验证与预算下比较，新增方法需要对照和消融；检索候选模态、ID和10项唯一性校验单独验证。

## 单卡算力安排

与第5题共享5090，所有GPU命令通过run_job.py --gpu-lock /root/autodl-tmp/cunsl-2026/gpu.lock取得Linux文件锁，再查询现有GPU计算进程；占用时退出或有限等待，绝不终止另一题任务。锁文件内容只是记录，是否占用以flock为准。数据下载、CPU审查和CPU指标核对不持GPU锁。长任务保存日志、随机种子、配置和检查点。

真实DINOv2/v3前向、适配器训练/反向、DINOv3-B末4块图像微调与检查点推理已在该实例运行，具体阶段用时与PyTorch显存峰值已记录。不据此承诺全编码器解冻或其他模型的耗时。

## 下一轮优先级

识别效果为优先目标。两组本地验证均支持DINOv3-B监督微调作为当前主线，O2S/S2O R@1仍仅约20%。先审查错配样本，固定两组划分、输入与训练预算，对损失、翻转增强和解冻范围做消融；再评估模态独立patch输入、局部结构对齐与灰度/深层特征融合。新结构和增强尚未实测，每项结果继续独立指标复算和检查点恢复；全训练身份重训与10月4日后的有限提交在方案确定后归档。具体已完成结果与边界见[第9章](09-modern-models.md)。
