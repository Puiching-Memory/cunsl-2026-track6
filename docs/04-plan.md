# 研究执行与验证计划

## 顺序与验收

当前已完成数据审查、身份隔离协议、初始基准、DINOv3通用/卫星对照、真实错配分析，以及两组划分的分模态入口/结构损失消融。固定协议见[第7章](07-validation.md)，初始基准见[第8章](08-baselines.md)，骨干升级见[第9章](09-modern-models.md)，领域机制与最新复现见[第10章](10-domain-research.md)和[第11章](11-domain-ablations.md)。不能据两组同源本地验证宣称最佳方法。

1. 完成官方包下载，运行摘要/CRC审查；确认是否含训练数据，再核对标签和真实task.json。
2. 全量解码TIFF，统计模态、尺寸、通道与身份数据；核验灰度复制和异常文件，保留可追溯记录。
3. 使用身份隔离的固定本地验证协议；三个检索方向分别列出R@1、mAP@10与加权分。验证身份不进入训练。
4. 在具体训练包与来源清单齐全后登记通用检索基准；所有外部权重先完成2026-09-01公开日期与许可审查。
5. 模型研究只在固定验证与预算下比较，新增方法需要对照和消融；检索候选模态、ID和10项唯一性校验单独验证。

## 单卡算力安排

与第5题共享5090，所有GPU命令通过run_job.py --gpu-lock /root/autodl-tmp/cunsl-2026/gpu.lock取得Linux文件锁，再查询现有GPU计算进程；占用时退出或有限等待，绝不终止另一题任务。锁文件内容只是记录，是否占用以flock为准。数据下载、CPU审查和CPU指标核对不持GPU锁。长任务保存日志、随机种子、配置和检查点。

真实DINOv2/v3前向、适配器训练/反向、DINOv3-B末4块图像微调与检查点推理已在该实例运行，具体阶段用时与PyTorch显存峰值已记录。不据此承诺全编码器解冻或其他模型的耗时。

## 下一轮优先级

识别效果仍为最终目标。当前实测参照保留DINOv3-B独立光学/SAR入口、共享主干末4块监督微调，O2S/S2O R@1约21%–23%。用户已将算力机下线，并希望先积累领域经验、寻找更忠实的表示。2026-10-02本地研究见[第12章](12-representation-study.md)：先理解可见局部、缺失与背景的不同语义，检查多光学图身份与普通单对身份的图像呈现差异；暂未选定新结构。

恢复计算条件后，先补齐独立入口模型的候选覆盖诊断，再把有证据支持的局部/背景或增强假设拆成对照。固定两组协议，分别报告三个方向；局部布局应比较保留与打乱，缺失处理应检查是否放宽异船匹配，新增模块与更长训练分开。现有结构损失效果不一致，暂不保留。外部具体权重/数据继续逐项核验日期许可及接口；全训练身份重训及有限提交另行归档。旧模型的标签oracle不是可实现分数。
