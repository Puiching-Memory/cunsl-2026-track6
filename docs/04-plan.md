# 研究执行与验证计划

## 顺序与验收

1. 完成官方包下载，运行摘要/CRC审查；确认是否含训练数据，再核对标签和真实task.json。
2. 全量解码TIFF，统计模态、尺寸、通道与身份数据；核验灰度复制和异常文件，保留可追溯记录。
3. 使用身份隔离的固定本地验证协议；三个检索方向分别列出R@1、mAP@10与加权分。验证身份不进入训练。
4. 在具体训练包与来源清单齐全后登记通用检索基准；所有外部权重先完成2026-09-01公开日期与许可审查。
5. 模型研究只在固定验证与预算下比较，新增方法需要对照和消融；检索候选模态、ID和10项唯一性校验单独验证。

## 单卡算力安排

与第5题共享5090，使用独立track6工作目录，顺序运行以避免两项实验互相抢显存。先核对小规模前向/反向和图像读取；确认实际显存后才设置批量。长任务保存日志、随机种子、配置和中断检查点。

当前不承诺训练耗时。GPU合成运算通过仅说明环境功能正常；本题真实吞吐、精度和资源消耗需实际测量。

## 实验记录模板

| 字段 | 要求 |
|---|---|
| 输入与划分 | 包摘要、身份划分摘要、输入处理 |

| 训练 | 随机种子、优化设定、实际预算、代码提交 |
| 结果 | 三方向两项指标、总分、显存峰值、训练/推理时间 |
| 状态 | 成功/失败/中断，完整日志路径 |
