# 直接配对监督微调TransOSS中后段

2026-10-09。密集交互模型的第一种子0.688641未在第二种子复现，后者0.627386；交互混合程度的32身份诊断中，较好种子反而混合更强，不支持把差种子失败归因于节点过度混合。停止仅为该结构尝试门控、归一化或更多种子。

## 更强假设

现有配对头只在冻结的图像特征上学习。新的改动允许局部匹配损失直接更新产生中层局部节点的Transformer，同时允许全局配对损失更新CLS表征。训练身份和输入保持；这改变特征本身，而不继续修饰排名尾部。

为适配本地16GB，冻结前3层/双模态stem、位置及模态嵌入，将已审查原生模型第3层含CLS的完整257×768输出以float32无损保存，训练阶段从第4层继续到第12层。所有7,409张训练/验证图的CLS和第6层4×4局部节点均与原模型逐批精确重放，局部节点摘要也与原缓存完全相同。提取124.98秒，GPU allocated880MiB；没有测试图像。

## 预先固定的匹配对照

两组均从原生第三版骨干和官方第五版选中局部头(seed20261009，epoch10)加载，不使用新交互结构。固定原训练身份的CLS均值难度，随机锚点组成16个不同训练身份，每个随机选一个光学/SAR观测，每轮177批，共6轮。样本、候选、优化器更新数和每轮验证频率相同，逐轮摘要核对。对照冻结所有骨干；实验组允许第4–12层和final norm接收梯度。classifier/BN neck以及CLS配对头均冻结，局部判别器可训练。

目标：双向成对CE + 0.5局部分支独立双向CE + 0.5冻结classifier身份CE。身份CE通过冻结classifier对图像特征传播梯度；对照组为常数，实验组限制特征漂移。配对训练不通过原forward_encoded的no_grad分支，而显式计算冻结CLS头的logit，让实验组的输入特征仍有梯度。局部节点float16量化与旧头缓存一致，类型转换保留梯度。

局部头AdamW lr1e-4，骨干后段AdamW lr1e-5，weight decay均0.01，不扫描权重或LR。首段缓存无增强，所有suffix DropPath在两组都关闭；仅局部头保留原训练dropout。按原development每轮选择严格最佳，包含第0轮；固定原生前50候选、原O2O排名和同一复用报告组。该先导训练不是从完整原SGD/RNG状态精确续训，不能把模型优化器重启效果自动归因于配对目标。

阶段筛选仍要求显著检索/集合收益并复核另一指标，不能把本地增量换算官方提分。验证已复用，公开测试身份不参与缓存、采样、目标、拟合或早停。第一阶段只执行一组种子的冻结/解冻匹配对照；没有明显收益就不扩训练量。
