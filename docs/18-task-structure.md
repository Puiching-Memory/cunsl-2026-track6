# 从独立检索转向任务结构分析

2026-10-07。用户质疑DSMCL能否支持官方0.5→0.7–0.9的大幅提升，并提出比赛数据可能有特征泄露。重新读取正式ZIP内README、task.json、既有赛题规则记录，复查9,489张图的TIFF标签和像素审查，另做有标签留出数据的条件模拟。**发现明显Query/Gallery重复与任务耦合；尚未证明测试身份泄露或其他队伍使用了该结构。** 本轮无GPU、额外算力费、隐藏集评分或新提交。

## 哪些已验证，哪些还没有

用户下载目录的赛题readme实际为0字节；正式ZIP内训练README有内容，说明公开标签四列及匿名命名。初步审查时网页抓取不可访问、Edge请求头策略加载失败，内置浏览器停在组织登录页。2026-10-07晚Edge恢复后已重读官方五页；文字没有保证共同120身份，也没有直接禁止公开图像的联合重排序。有限规则解读与后续压力实验见[第19章](19-cohort-robustness.md)，不是主办方对具体方法的明确认可。

公开task.json只有queries和gallery，不包含隐藏ship_id。现有规则记录要求跨模态同身份检索，三方向按0.45/0.45/0.10加权，禁止非公开位置、AIS、成像时间等辅助信息。任务中的公开像素重复与未知身份标签是不同证据；不能把包装文件的修改时间当物理成像时间。

## 实际数据结构

使用正式包的全量像素SHA核对，不靠视觉近似。结果：

| 方向 | Query数 | 同模态Gallery完全相同副本 | 合法目标模态完全相同副本 | 与其他方向Query重复 |
|---|---:|---:|---:|---:|
| O2S | 120 | 93张光学副本 | 0 | 27张，与O2O配对重复 |
| S2O | 120 | 120张SAR副本 | 0 | 0 |
| O2O | 27 | 0 | 0 | 27张，与O2S配对重复 |

S2O的120张中有1张全黑，同时和训练/图库全黑图重复；该图没有身份区分能力，不能用它建立可靠身份关系。其他测试图与训练图没有完全相同像素。所有TIFF均只有同一组10个基础图像标签，没有字符串标签、原文件名、地理位置或身份文字。这里只排查了容器标签，并未排除像素层面的构造偏差或公开源数据重叠。

文件编号并不直接提供目前已验证的对应关系：Query编号与其同模态副本Gallery编号的线性相关系数，O2S/S2O均约-0.032。没有得到可靠的简单编号规则；这不能排除复杂排序、随机种子或其他构造规律。

**重要区别：这些副本不能直接作为跨模态答案提交。** O2S必须交SAR，S2O必须交光学；完全相同副本都在源模态中。此前数据审查记录了212个非恒定Query/Gallery重复组，但训练、验证和推理继续把所有Query独立处理，没有研究这些副本能否在任务之间传递对应关系。这是此次重新检查发现的路线缺口。

## 联合匹配的关键假设

值得核实的假设是：120张O2S光学Query与120张S2O SAR Query是否覆盖同一批120个不同身份，每个身份各一张。**人数相等和源模态重复不能单独证明它。** 需要官方数据构造说明、允许范围内的进一步像素/结构证据或后续实际验证。

如果成立，则可以：

1. 在120×120光学/SAR查询相似度矩阵上做一对一最大总相似度分配，利用整批图像的竞争关系。
2. 已匹配的SAR Query通过像素完全相同副本映射到合法SAR Gallery，得到O2S首位候选。
3. 反向匹配到光学Query后，93张通过光学Gallery副本映射；其余27张用对应O2O检索寻找另一张合法光学图，得到S2O首位候选。
4. 首位后的候选保留原全Gallery排序，维持十个唯一合法ID，并避免把相关项从AP分母中人为删掉。

这把独立的900候选检索转成共同查询集合内配对，再通过已验证像素关系落到Gallery。它仍需要模型识别跨模态图像，并不是拿到了隐藏标签。错误的查询集合假设会强迫错误匹配；共享身份存在重复观测时，一对一约束也需要调整。

## CPU条件模拟：大幅信号已经出现

只读取已保存的TransOSS留出特征，不重新训练或运行测试推理。在有标签的验证身份里，构造120个共同身份，各选一光学/一SAR Query；其中27个身份有第二张光学图，删去这27张光学Query的Gallery自身副本并重复用作O2O Query。其余93张光学及全部120张SAR Query仍在对应Gallery。20次固定种子20261007–20261026抽样，每次独立打乱两个模态查询顺序。

**标签用于构造这个假设场景和评分。** 相似度、分配、桥接算法不读取身份标签，但模拟本身保证了尚未证实的共享身份条件，属于强先验下的收益测试。图库为718张SAR/738张光学，比官方900/900小；这些是反复选过模型的同一个留出集，不能将其当新独立验证或官方预测。

| 同一模拟协议，20次平均分 | 已提交第三版CLS | 上轮联合训练CLS |
|---|---:|---:|
| 独立全Gallery检索 | 0.532685 | 0.540029 |
| 只用查询集合挑O2S首位，其他原样 | 0.619702 | 0.617231 |
| 一对一分配，仅改变O2S首位 | 0.665721 | 0.668675 |
| 一对一分配＋双向像素桥接/O2O衔接 | **0.799670** | **0.801170** |

第三版完整联合模拟20次范围0.722785–0.883410，相同模拟独立基线范围0.474417–0.585568，平均增量+0.266985。上轮联合模型为0.740560–0.865201，平均增量+0.261141。不是第三版原验证0.560496或官方0.514408直接涨到0.80；查询抽样、图库和先验约束改变了。

第三版联合模拟O2S R@1/mAP@10平均0.779167/0.818323，S2O为0.776667/0.806366，O2O仍为原光学检索0.812963/0.868078。上轮联合模型几乎没有在这个协议上再超过第三版；大幅变化来自任务结构，而不是新增训练损失。

最大权分配采用独立的匈牙利最短增广路径实现，对2–6阶随机矩阵共15次与枚举所有排列的最优目标交叉核对，所有通过。未把生成查询时的相同身份顺序交给匹配算法。排名按完整Gallery正样本数计算原AP口径，模型和特征摘要绑定保存。

压力检查把24个SAR查询替换成查询光学集合之外的身份，只改变查询集合关系：第三版O2S联合方案方向分从0.798745降到0.583428，上轮模型从0.802744降到0.585703。这里不是完整三方向压力分数，也不是置信区间；它说明共同身份假设错误会显著损害效果。若两查询集合身份完全不相交，硬分配的所有O2S首位都将错误，因此不能无证据强制闭集匹配。

原始模拟记录、私有对应关系和脚本留在local/dsmcl；[匿名证据](evidence/2026-10-07-task-structure.json)仅保存统计、设置、摘要和条件结果。

## 对研究优先级的调整

目前没有充分理由预期DSMCL单项能把官方0.5推到0.7–0.9；它的实现保留作为后续表示改进候选。更高优先级是**核实公开任务生成结构，再做跨方向联合匹配**。这个方向已在明确假设下出现+0.26量级的CPU信号，优先级高于继续同一验证集微调小损失。

官方文字已补齐，可放弃匹配的部分分配与双向间隔控制也已完成CPU压力实验。共同身份条件明显影响收益，单一余弦阈值或互近邻都不能保证不误配，详见[第19章](19-cohort-robustness.md)。后续优先核实公开查询结构，并比较完整Gallery竞争证据；裁剪、黑边、方向和背景一致性仍是待查线索，不能预先称为身份真值。正式预测仍需单独记录假设、完整模型/文件版本及官方结果，不能声称榜首使用了本方法，也不能把0.800作为预计官方分数。
