# 光学/SAR舰船重识别：领域研究与针对性对照

本章将论文主张、作者代码、本地观察和待验证假设分开。阅读对象是直接处理光学/SAR舰船身份检索的 TransOSS、MOS 和 SDF-Net；未导入它们的数据集、预训练权重、生成图像或辅助元数据。DINOv3 继续作为已审查的通用初始化，领域机制必须通过本题协议验证。

## 成像机制决定我们应当对齐什么

光学外观取决于可见光反射；SAR 是主动微波后向散射观测，亮度还受散射几何和相干干涉影响。双次反射、散斑及侧视投影意味着“光学转灰度”并不能得到同一艘船的 SAR 外观，刚性船体也不保证逐像素位置一致。成像基础参考[ASF的SAR原理](https://hyp3-docs.asf.alaska.edu/hyp3-docs/guides/introduction_to_sar/)。

本题实测 SAR 是 uint8 三通道灰度复制，未提供复数雷达回波、极化或标定参数。因此不能将 RGB 三个通道当作三种极化，不能声称恢复了雷达相位，也不能把已经量化的像素当作原始散射强度校准。图像傅里叶变换的相位与雷达回波相位是不同概念。船体比例、轮廓及部件布局是可尝试的身份线索，其跨模态稳定程度仍须实测。

## 三条直接相关的研究路线

| 来源 | 机制及阅读结论 | 在本题中的取舍 |
|---|---|---|
| [TransOSS，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Wang_Cross-modal_Ship_Re-Identification_via_Optical_and_SAR_Imagery_A_Novel_ICCV_2025_paper.pdf) | 分模态 patch 输入、共享 ViT；先用光学/SAR场景对做对比预训练，再做身份监督。还添加模态及尺寸信息。 | 先测试独立图像入口；固定已有初始化，避免把外部配对预训练收益混入结构收益。 |

| [SDF-Net，arXiv v1，2026-03-13](https://arxiv.org/abs/2603.12588) | 中间层梯度能量标准化后按身份跨模态约束；末端共享/模态特定表示经正交约束和相加融合。 | 把中间层结构约束拆出来单测，不同时增加解耦分支，也不称完整复现。 |

原始 HOSS 协议的跨模态 Query/Gallery 规模分别为 O2S 65/190、S2O 67/403，另有混合模态 All-to-All；评价使用全 Gallery 的 mAP。本题验证使用约700个目标模态候选、mAP@10，以及独立 O2O 任务。论文成绩不能当作本题预期分数，All-to-All也不能替代 O2O。

## 固定作者代码后的复现注意点

代码快照选取截止日前的提交，原文、代码和许可存于 Git 外；固定版本与摘要汇总见[阅读证据](evidence/2026-10-01-domain-sources.json)。三项根目录代码 LICENSE 为 MIT，未据此推断其数据或权重许可。

- TransOSS 固定 `bd9b9028e8690c0929ada06beead500acde19aca`。其[数据入口](https://github.com/Alioth2000/Hoss-ReID/blob/bd9b9028e8690c0929ada06beead500acde19aca/datasets/bases.py)在统一 resize 前，根据原始裁剪尺寸与 GSD 生成尺度信息。本题不能用统一256像素或阈值包围框冒充实际船长；未使用任何外部位置、成像时间或尺度元数据。
- MOS 固定 `793dc39ef828bbd77c59570aa081389620345e06`。检查[实际对齐损失](https://github.com/yjzhao1019/MOS/blob/793dc39ef828bbd77c59570aa081389620345e06/loss/make_loss.py)发现使用归一化特征均值/方差之差的欧氏范数，与论文平方范数写法有别；一张/模态时方差项为零。截止日前的代码未含后来 README 对融合权重的更正；当前作者说明改为0.02。9月发布的生成样本不能因论文较早就视为符合本题资源截止日。
- SDF-Net 固定 `15cbb1a88742256c9a6754d4f29f956991366f93`。[实际骨干](https://github.com/cfrfree/SDF-Net/blob/15cbb1a88742256c9a6754d4f29f956991366f93/model/backbones/vit_transoss.py)取相邻 patch 差分，正文公式写为跨两格差分；[末端实现](https://github.com/cfrfree/SDF-Net/blob/15cbb1a88742256c9a6754d4f29f956991366f93/model/make_model.py)使用共享/模态特定 token，而不是直接照搬文字所述的两个末端线性投影。正交内积小不能证明统计独立，梯度标准化也不保证空间缩放或视角不变性。

[FD-GA，JSTARS 2026，DOI](https://doi.org/10.1109/JSTARS.2026.3708907)提供频域与拓扑方向的线索。IEEE标记出版日期为2026-07-01，Crossref登记时间也为7月1日。本轮读取的是出版方索引的摘要、引言及部分方法，尚未读完整PDF或核验作者实现/权重；未作为复现结果或已审查资源使用。其正交约束和拓扑不变性主张仍需实测，不能把图像频域相位与雷达回波相位混为一谈。

## 配对预训练与遥感基础模型仍值得研究

领域预训练应学习同一场景在两种传感器下的关联，但场景配对不等于同船身份配对，也不保证舰船局部逐像素对齐。当前DINOv3通用/卫星初始化均不是经过本题SAR身份训练的表示，不能因其更新就跳过领域适配。更相关的公开候选如下，均未导入：

| 来源 | 相关性 | 接入前必须解决的问题 |
|---|---|---|
| [CROMA，NeurIPS 2023官方实现](https://github.com/antofuller/CROMA) | 雷达/光学对比学习与掩码重建预训练 | 原接口是Sentinel-1两通道和Sentinel-2十二波段，默认120像素。本题RGB及灰度复制不提供缺失的真实波段，需单独设计输入适配。具体权重日期及许可尚未审查。 |
| [AnySat，CVPR 2025 Highlight官方实现](https://github.com/gastruc/AnySat) | 多传感器、多尺度JEPA表示 | SAR分支使用VV/VH或VV/VH/比值及日期序列，模型另有物理尺度假设。本题未公开这些信息，不能伪造极化、成像日期或GSD。具体权重审查未完成。 |
| [SOMA-1M作者数据页](https://github.com/PeihaoWu/SOMA-1M) | 大规模配准光学/SAR场景对，可作为配对预训练的研究线索 | 作者说明分批发布，当前页面提供测试子集。论文发布时间不证明某个训练子集在截止日前公开，更不替代第三方影像权利核验。未下载数据。 |

因此，下一步要比较的是“经过合规审查的配对预训练能否迁移到同船检索”，而不是直接按遥感基础模型的榜单排名选型。

## 本题真实错误揭示的优先问题

使用第9章固定入口12轮微调的保存特征，对两组验证集计算完整 Gallery 排序；前十候选与原报告逐项一致。没有使用初赛隐藏身份或测试数据统计。匿名汇总见[错配证据](evidence/2026-10-01-retrieval-errors.json)，案例原图和身份清单仅留在 `local/error-analysis/`。

| 划分 | 方向 | R@1 | R@10 | 正确候选在第2–10名 | 正确候选在第10名以后 |
|---|---|---:|---:|---:|---:|
| seed 20261001 | O2S | 20.78% | 67.97% | 361/765 | 245/765 |
| seed 20261001 | S2O | 21.57% | 64.99% | 310/714 | 250/714 |
| seed 20261002 | O2S | 20.21% | 63.78% | 332/762 | 276/762 |
| seed 20261002 | S2O | 20.03% | 61.61% | 299/719 | 276/719 |

这说明既有候选内排序问题，也有检索表示问题。R@10只要求至少一个正确候选，不能当成mAP@10；更不能把正确候选已在前十的比例当作无需训练即可达到的成绩。

原始训练标签有3,534个身份，其中3,325个只有2张图，占约94.09%。本轮每批每身份取1张光学和1张SAR；论文多实例均值/方差估计不能直接套用，重复同一张图也不会产生新的身份观测。

观察像素大于8的区域占比：首划分 O2S 中，占比90%以上的593个光学 Query 的R@1为17.54%；占比12%–30%的143个Query为33.57%。第二划分对应17.87%和26.76%。实际查看前者样本可见港口/海面背景，后者常见黑色填充的裁剪。这是相关性及抽样观察，没有人工真值分割，也未证明背景是唯一原因。

两组O2O分别只有44/40个Query，均没有上述90%以上占比的光学图，而O2S有593/582个。O2O还要求同身份至少两张光学图，选择出的身份及裁剪类型与跨模态任务不同。因此O2O高、O2S低同时包含任务选择与图像分布差异，不能把全部差距归因于传感器。

SAR占比1%–3%的Query在两组S2O中的R@1约16%–17%，12%–30%的Query约30%–31%；小占用区域较难，但占比同时受强度与阈值影响，不能直接等同船体面积。现有 `cls_foreground` 的阈值掩码可能在光学图里覆盖整幅背景，在SAR里只覆盖亮点，必须保留“不是舰船分割”的边界。

## 有依据的等预算实验

保持同一DINOv3-B/16初始化、256输入、CLS加阈值区域池化、末4块、32对身份、12轮、学习率及原有三项检索损失。只改变以下变量，配置见[领域对照配置](../configs/domain-ablation.example.toml)：

1. **固定入口控制**：复算原方法，确认代码扩展没有改变旧结果。
2. **共享入口可训练**：释放同一个 patch 输入层，区分“入口可学习”和“分模态”收益。
3. **光学/SAR入口可训练**：两个入口从完全相同的已审查权重复制，之后分别学习，共享Transformer。
4. **增加第6层结构约束**：在第三项之上，排除CLS和4个register，统计横纵相邻patch差分能量，按图像在通道维标准化，配对MSE权重1。这个约束能通过可训练入口传播梯度；只训练末4块时，第6层约束若无可训练路径就没有优化作用。

所有变体用固定最后一轮模型，不按验证分数挑选训练检查点；比较的是等样本及等轮数预算，新增参数和耗时另报，不能称等参数或等算力。两组划分共享训练包，不能视为独立外部测试。实际实验、失败记录、三方向结果与恢复核对见[领域消融实测](11-domain-ablations.md)。

## 后续决策标准

本轮两组结果支持保留独立入口学习；第6层结构约束的效果不一致，暂不放入下一基线。中间层能量损失只是结构线索的一种实现，其失败不能否定所有几何建模。

下一轮先对照不依赖外部检测权重的局部池化和背景处理，再单独测试保持完整船体的旋转/翻转、模态强度增强。SAR相干散斑和光学纹理不同，不把任意乘性噪声当作真实SAR模拟；裁掉船首/船尾也可能删除身份线索。随后审查配对预训练资源，并在同一两组协议上比较。局部图匹配、解耦分支和扩散生成属于后续候选，只有简单控制仍受限时再投入。每个方向均需对照，不能继续用“大模型更新”代替领域问题分析。
