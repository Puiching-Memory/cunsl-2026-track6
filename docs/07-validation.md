# 固定身份隔离协议

协议版本identity-holdout-v1，种子20261001，目标验证身份比例20%。只使用公开训练标签和训练图像审查结果建立划分，不使用测试身份、测试图像相似度或测试预测进行划分。

## 异常与泄漏控制

先隔离常量训练图和完全相同像素但身份冲突的训练图；同身份的完全相同像素副本只保留一张。浮点dHash≤2且16×16标准化缩略图相关≥0.9998的训练图像，以身份建立连通分组，整个分组分配至同一分区。按种子与分组最小身份ID的SHA-256确定分组顺序。

本包隔离13张训练图；得到3,487个身份分组，最大含3个身份。实际训练2,827个身份/5,926张图，验证707个身份/1,483张图。身份、像素摘要及所用近重复候选边均无跨区重叠。

划分文件SHA-256：`b33cbea7e9d9771f12ee4f507ef13a868fe0f3be0d1a4c77bbbc1290402e5bd5`。labels.csv、正式包及用于决策的训练审查结果摘要绑定到划分文件；审查时间和用时不会改变划分摘要，JSON统一使用LF换行保证跨平台摘要一致。load_split重新检查元数据摘要、身份名单、覆盖、检索模态、Query/Gallery不交叉和每Query有效正样本。

## 三方向构造

| 方向 | Query | Gallery | 构造 |
|---|---:|---:|---|
| O2S | 765 | 718 | 具有有效SAR同身份正样本的全部验证光学图；全部验证SAR为Gallery |
| S2O | 714 | 765 | 具有有效光学同身份正样本的全部验证SAR图；全部验证光学为Gallery |
| O2O | 44 | 721 | 至少2张有效光学的验证身份各取1张Query；其余全部验证光学为Gallery |

O2O Query由种子与image_id摘要确定，不按模型表现挑选。每个方向内Query不出现在Gallery；不同方向可重复使用验证图像。未配对验证图仍可作Gallery干扰项。候选不足10或任一方向无Query时拒绝该划分。

## 指标口径

R@1为第一位是否同身份的Query平均值。AP@10为前10位中每个正样本所在位置的precision之和，分母显式选择：

- min_relevant_k：min(该Query在整个目标Gallery的正样本数, 10)。
- all_relevant：该Query在整个目标Gallery的正样本数。

两种口径都记录；禁止自动默认一种并称为官方实现。本验证集每Query正样本最多3个，所以两种分母目前数值相同，这不能证明已匹配正式评分程序。另用20个正样本的合成例子检验两种分母确有差别。零正样本Query被拒绝，不静默跳过。

三个方向分别报告R@1、mAP@10及平均分，按0.45、0.45、0.10加权。排序前按目标模态构造Gallery，余弦分数相同时按Gallery ID字典序确定，输出10个唯一ID。正式测试由公开query_type和Gallery modality控制筛选。

## 局限

此协议是本地身份泛化验证，Gallery规模和方向比例不完全等于正式测试。O2O只有44个Query，且可能含相似取景，因此单次结果有较大不确定性。训练标签存在已观察到的冲突，启发式近重复分组也不能穷尽原始来源关联。下一阶段需独立种子划分、错误审查和相同预算对照，才能讨论稳定提升。
